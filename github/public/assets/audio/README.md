# Áudios incluídos no projeto

Esta pasta está reservada para arquivos que devem acompanhar uma publicação.
O acervo original não forneceu MP3s. Nenhuma gravação é inventada ou criada automaticamente.
Uploads pelo painel ficam no IndexedDB daquele navegador e NÃO são copiados para esta pasta.
Para transportar esses uploads, use Exportar/Importar pacote no gerenciador.
Para distribuir um pacote já preparado junto do site, consulte docs/GITHUB.md.
